⚠ Limitations

Code implemented on custom fields relies heavily on the order of the custom fields, from top to bottom. If the order is changed, or a new custom field is added and inserted somewhere that isn't the bottom of the list, the custom code generated by this tool will break.

For very complex situations, we recommend enabling Custom CSS: Dashboard and adding this code snippet. It hides the buttons used to re-arrange and delete custom fields. This will help prevent accidental changes that break the code.

Please see this short video for more information: https://view.thnk.cc/rRue74Qr

/* This bit of code hides the delete button, and drag button on custom fields in the settings. This is recommended when complex custom code is used to enhance custom fields. If you wish to re-order or delete a custom field, please make sure your custom code is adjusted appropriately */ #settings .toga-icon-handle-drag, #settings .delete-def-btn { display: none; }
